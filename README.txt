# Sorpresa de cumpleaños + 10 meses ❤️

## Archivos
- `index.html` — página principal
- `styles.css` — diseño
- `script.js` — interacción
- `assets/cancion.mp3` — coloca aquí tu canción
- `assets/video.mp4` — coloca aquí tu video

## Publicarla gratis
La opción recomendada es GitHub Pages.

1. Crea un repositorio público en GitHub, por ejemplo: `sorpresa-doctorita`.
2. Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets`.
3. En Settings → Pages, selecciona publicar desde la rama `main` y la carpeta `/root`.
4. GitHub generará una dirección `https://TUUSUARIO.github.io/sorpresa-doctorita/`.
5. Abre esa dirección desde tu celular para probarla.
6. Genera el QR con esa URL.

## Importante
En celulares, la música no puede depender de autoplay. Por eso la página tiene el botón inicial "Abrir mi sorpresa"; al tocarlo se inicia la canción.

No pongas información privada en el repositorio. GitHub Pages es público.
